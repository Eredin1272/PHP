##  Шаг 1: Нативные PHP-шаблоны

###  Реализация

Было выполнено разделение:
- **Логика** — в `src/`
- **Шаблоны** — в `templates/`

###  Пример (index.php)

```php
$data = getData();

include 'templates/layout.php';
```

###  Пример шаблона (list.php)

```php
<?php foreach ($data as $item): ?>
    <tr>
        <td><?= htmlspecialchars($item['name']) ?></td>
    </tr>
<?php endforeach; ?>
```

###  Особенности
- используется `include`
- данные передаются через переменные
- логика минимизирована

##  Шаг 2: Twig

###  Установка

```bash
composer require twig/twig
```

### 🔧 Настройка

```php
require 'vendor/autoload.php';

$loader = new \Twig\Loader\FilesystemLoader('templates_twig');
$twig = new \Twig\Environment($loader);
```

---

##  Twig-шаблоны

###  layout.twig

```twig
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}My App{% endblock %}</title>
</head>
<body>
    {% block content %}{% endblock %}
</body>
</html>
```

###  list.twig

```twig
{% extends "layout.twig" %}

{% block content %}
<table>
    {% for item in data %}
        <tr>
            <td>{{ item.name }}</td>
        </tr>
    {% endfor %}
</table>
{% endblock %}
```

---

##  Наследование шаблонов

Twig использует:

- `{% extends %}` — наследование шаблона  
- `{% block %}` — переопределяемые блоки  

Это позволяет:
- избежать дублирования кода  
- централизовать layout

## 🔧 Дополнительное задание (10 баллов)

### ✔️ Пользовательский фильтр

```php
$twig->addFilter(new \Twig\TwigFilter('upper_custom', function ($string) {
    return strtoupper($string);
}));
```

###  Использование

```twig
{{ name | upper_custom }}
```

##  Контрольные вопросы

### 1. Отличие PHP-шаблонов и Twig

| PHP шаблоны | Twig |
|------------|------|
| Чистый PHP | Специальный синтаксис |
| Можно писать любую логику | Логика ограничена |
| Менее безопасно | Безопаснее (escaping) |
| Простота | Более структурировано |

**Вывод:**  
Twig лучше подходит для крупных проектов.

---

### 2. Зачем разделять логику и представление?

Причины:
- удобство поддержки  
- читаемость кода  
- повторное использование  
- безопасность  

Проблемы без разделения:
- смешивание HTML и PHP  
- сложность отладки  
- плохая масштабируемость  

---

### 3. Наследование шаблонов в Twig

- `{% extends %}` — подключает базовый шаблон  
- `{% block %}` — определяет изменяемые части  

Пример:

```twig
{% extends "layout.twig" %}

{% block content %}
    Контент страницы
{% endblock %}
```
